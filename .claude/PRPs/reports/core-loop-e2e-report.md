## Deviations from plan

1. **`home-goal-progress` doesn't exist** — home screen has no goal section; asserted `home-recent` + `-₺500,00` instead.
2. **Release build instead of debug+Metro** — `clearState` broke Metro host connection; `expo run:android --variant release --no-bundler` gives deterministic embedded bundle.
3. **Id-based selectors only** — device locale is English, Turkish text assertions ("Atla", "Yeni İşlem") fail. Currency assertion kept: `formatCurrency` locks `tr-TR`.
4. **Skip selector race** — `onboarding-skip` exists on every onboarding step; flow waits for `notVisible: onboarding-income-name` before tapping skip on the recurring step.
5. **Keyboard handling** — soft keyboard covered `login-submit`; fixed with `hideKeyboard` immediately after password input (keyboard guaranteed open there). On the income form the keyboard auto-dismisses, so no `hideKeyboard` (adding one sent the app to background via back-key). Disabling IME via adb does NOT work — Maestro re-enables it.
6. **Expo Go interference** — must `adb shell am force-stop host.exp.exponent` before runs, else Maestro drives Expo Go.

## Known limitations / follow-ups

- Flows run against the **current `.env` Supabase project** (user's explicit choice); test users accumulate — cleanup SQL in `.maestro/README.md`.
- When email confirmation is enabled (P0 backlog), flow 01 must switch to sign-in with a seeded pre-confirmed user.
- `android/` directory generated by prebuild is untracked — decide whether to commit or gitignore.
